# MSMM — лендинг

Одностраничный сайт на чистом **HTML + CSS + JS** (без сборки и зависимостей).

## Структура

```
msmm/
├─ index.html      # разметка всех секций
├─ css/styles.css  # стили и адаптив
├─ js/script.js    # меню, анимации, форма
└─ README.md
```

## Запуск

Просто откройте `index.html` в браузере (двойной клик).
Или локальный сервер:

```bash
python3 -m http.server 5500
# затем откройте http://localhost:5500
```

## Секции

- **Hero** — заголовок, оффер, кнопка
- **Обо мне** — «Результат, эстетика и подход» (4 преимущества)
- **Услуги** — «Что я делаю» (копирайтинг / дизайн / продвижение)
- **Портфолио** — «Работаю с нейросетями» + 5 работ
- **Этапы работы** — 4 шага
- **Контакты** — форма + мессенджеры

## Как заменить заглушки на реальные фото

**Hero.** В `index.html` внутри `<div class="hero__photo">` удалите `<svg …>` и вставьте:

```html
<img src="images/hero.jpg" alt="Рабочее место" />
```

**Портфолио.** В каждой карточке `.work__img` замените `<span>…</span>` на:

```html
<img src="images/matrix.jpg" alt="Матрица судьбы" />
```

Плейсхолдеры-градиенты (`.work__img--tarot` и т.д.) в CSS можно оставить —
они просто не будут видны под изображением.

## Что настроить перед публикацией

- Контакты в секции `#contact`: e-mail, Telegram, Instagram (сейчас заглушки).
- Отправка формы: в `js/script.js` (комментарий «Здесь можно отправить данные…»)
  подключите свой обработчик — например, [Formspree](https://formspree.io),
  Telegram-бота или собственный бэкенд.
- Мета-теги и `<title>` в `index.html`.

## Особенности

- Адаптив от 320px до десктопа, мобильное бургер-меню.
- Плавная прокрутка, подсветка активного пункта меню, анимация появления секций.
- Учитывается `prefers-reduced-motion`.
- Шрифты Google Fonts: Playfair Display, Montserrat, Cormorant Garamond.
